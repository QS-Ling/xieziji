AI × SHARED PAPER

共享写字台，连接自己的 AI。

同一台机器的文字、预览、文档库和书写进度始终共享。任何已获服务访问权限的网页都可以直接查看、手动编辑和操作机器。只有 AI 接口采用轮流占用：你退出 AI 档口，下一位再连接自己的 AI。

首次配置 · 日常配对 · 调用示例 · AI 交接 · 常见问题

1．首次配置：给自己的 AI 添加 MCP

每个人在自己的电脑上配置一次。AI 使用你自己的模型账号，写字台无需模型密钥。MCP 适配器在你的电脑运行，连接机器所在的业务服务器；你不用启动本机串口控制端。

下载 MCP 客户端 ZIP ↗

  1. 在自己的电脑安装 Python 3.10+，下载并解压上面的客户端包。
  2. 进入解压后的 zhijian-mcp-client 目录，创建独立环境并安装依赖：
python -m venv .venv-mcp
.venv-mcp\Scripts\python.exe -m pip install -r requirements-mcp.txt

下方填写自己电脑的绝对路径。使用虚拟环境时，Python 应填为 .venv-mcp/Scripts/python.exe 的完整路径。服务器地址需要从你的电脑能访问；另一台电脑上的服务不能填成本机 localhost。

Codex

将配置加入 Codex 的 config.toml，然后在新聊天使用。本机配对凭证默认保存在 ~/.zhijian-plotter/mcp-sessions.json；不要与同伴共享凭证文件。

DeepSeek Harness / DSH

保存为 writing.patch.yml，运行 npx @deepseek-ai/dsh web --patch ./writing.patch.yml。此配置加载官方 MCP 客户端插件；桌面版本的入口可能不同。

配置后应能看到 pair_workbench、read_workspace、create_document、update_document、get_preview_image 等工具。工具出现后，再进行日常配对。

2．占用 AI 档口，再连接自己的 AI

  1. 打开网页。无需占用，就能看到同一台机器的共享内容和当前书写进度，也可以手动编辑。
  2. 需要使用 AI 时，填写名称并点击“占用 AI 档口”。已有占用时，等待对方退出 AI。
  3. 选择实际设备，点击“连接我的 AI”，把生成的提示词发给自己的 DSH 或 Codex。
  4. AI 调用 pair_workbench 完成连接。一次性配对码 5 分钟有效，重新生成会使前一个码失效。

也可在 AI 中调用 claim_workbench 占用空闲档口，再把返回的网页配对码填到首页“已在 AI 中领取？”中。服务器有访问令牌时，直接占用需要本地 PLOTTER_TOKEN；从网页占用后配对时，AI 无需知道该长期服务令牌。

工具用途
read_workspace / describe_capabilities读取共享内容、版本和参数范围
create_document / update_document导入 AI 文档，或修改当前共享文档
preview_document试排，不替换网页当前内容
get_preview_image / get_preview真实纸面笔画 PNG / 排版指标
get_machine_state读取书写状态、进度和 ETA，不移动机器
save_document / list_documents / load_document保存和载入本机共享文档
release_workbench退出本轮 AI 占用

4．退出 AI，占用交接；文字和机器照常

点击“退出 AI 占用”，或让 AI 调用 release_workbench。正文、预览、文档库和进度都保留；其他网页始终可见。下一位占用 AI 后读取同一份共享内容，原 AI 的会话凭证立即失效。

机器书写期间也能交接 AI 档口，不会暂停、停止或重新提交正在写的页面。当前页执行已经生成的固定路径；网页或新 AI 修改内容，只影响后续生成的预览。每页完成后仍需人工换纸、确认原点，再开始下一页。

关闭浏览器不自动退出 AI，也不停止任务。可以在原浏览器重新打开；或通过“连接另一网页管理 AI”生成网页配对码，转到另一个浏览器管理同一轮 AI 占用。该配对不影响共享内容。需要立即停机时，使用网页“紧急停止机器”。

常见问题

  • 别人能否手动修改？可以。网页编辑不受 AI 占用影响；版本冲突会提示，保留本地修改并要求合并。
  • 进度与编辑区不一致？运行中任务使用固定路径，编辑区可以准备后续内容。查看机器状态、当前任务编号和进度，不能把新预览当成正在执行的内容。
  • AI 没有工具？检查自己的 Python 环境、脚本路径和 MCP 配置，重新连接宿主或新建聊天。
  • 配对失败？检查控制器 ID、配对码用途与有效期。AI 码与网页管理码不能混用。
  • 原 AI 无法继续修改？退出后本轮凭证已撤销，需要重新占用和配对。
  • 版本冲突？AI 应重新读取并合并，不能反复提交旧版本覆盖网页新内容。
  • AI 不能看图？需要宿主模型支持图像输入；仍可读取页数、范围等指标。
  • 连不上服务器？检查局域网地址、端口与访问令牌；跨不可信网络应使用 HTTPS 或受控隧道。

同一控制器下的设备端口各自保留工作区，切换端口不清除另一端口的文档。服务访问控制继续生效，“共享”仅指已获服务访问权限的用户。AI 不提供启动书写、点动或抬落笔工具，机器操作在网页确认。
