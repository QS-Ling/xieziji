# 笔迹变化

展开“手写仿真”，可启用字形缩放、旋转、基线、字距等变化，并与字体混排一起使用。关闭仿真后重新生成即可取消变化；已生成的预览和任务不受参数编辑影响。

| 参数 | 作用 |
| --- | --- |
| 笔画末端长短变化 | 对几何自由端做有限伸缩，支持单端或多自由端独立随机，避开闭合路径、连接点及邻近笔迹 |
| 断续连笔 | 在距离、方向及避让检查合适的相邻字之间添加连接，空白、标点、公式、换行与分页处断开，最多连三个字后抬笔 |
| 每行随机倾斜 | 对笔记行施加有限斜率，按实际路径范围保护边距，包含公式的整行不倾斜 |

连笔与行倾斜用于笔记模式，末端变化可用于两种模式。连笔概率只作用于合适候选，不代表相同比例的全部字都相连。可先用 3%–5% 的末端变化幅度，再逐步观察。

连笔方式包含短距衔接、牵丝连写和临帖引带。这些是几何规则，并非学习真实作者的笔迹，也不识别“横”“捺”等语义笔画。规则及参考来源保存在 `backend/cursive_rules.json`。

同一输入与种子可复现路径。预览、下载与执行使用相同的缓存笔画，修改设置后需重新生成。变化可能增加行数或页数，应在书写前检查最终预览；实际效果还取决于字库、笔、速度与机械条件。
